# Reviewer Checklist

- [ ] Original media, not SafeTrace output, was reviewed.
- [ ] Source path and vehicle/group are correct.
- [ ] Profile and canonical finding match the footage.
- [ ] Positive/negative/uncertain status follows the label definitions.
- [ ] Start/end timestamps cover one continuous event.
- [ ] Visibility is adequate for any positive or negative claim.
- [ ] Glare, blur, angle, darkness, and occlusion are documented.
- [ ] Multi-person target identity is clear.
- [ ] Simultaneous findings use separate rows.
- [ ] Confidence reflects evidence quality, not annotator certainty alone.
- [ ] Reviewer agreement or resolved disagreement is recorded.
- [ ] Training and held-out evaluation sources do not overlap.
